# Mineradio

> Windows 沉浸式音乐播放器，融合动态桌面模式、节奏镜头、歌词舞台、粒子视觉与 3D 专辑架。

![Mineradio 暗场启动页](./docs/assets/readme/cinema-beat-smoke.png)

Mineradio 是一款面向 Windows 桌面的沉浸式音乐播放体验应用。它将音乐播放、动态歌词舞台、粒子视觉特效、3D 专辑陈列架与桌面融合技术结合在一起，为音乐爱好者打造更具现场感与仪式感的私人听歌空间。

---

## 核心特性

- **动态视觉舞台**：
  - 基于音乐编曲与节奏（BPM）的电影级运镜与光影粒子特效；
  - 沉浸式动态歌词舞台，支持歌词逐字律动与位置微调；
  - 专属 DJ 模式与长曲目/播客沉浸式视觉场景。
- **3D 专辑陈列架**：
  - 3D 旋转歌单货架，支持封面悬停交互与播放队列无缝切换；
  - 支持自定义专辑封面上传、自动提取与裁切。
- **桌面与壁纸深度融合**：
  - 完整桌面沉浸模式（保留日常桌面操作与半透明视窗交互）；
  - 支持加载本地 MP4 视频壁纸与 Wallpaper Engine 视觉工程。
- **第三方流媒体与本地音源生态**：
  - 网易云音乐、QQ 音乐账号及歌单解析接入；
  - 正在增强：本地音乐目录深度递归扫描、内嵌 ID3/FLAC 标签与内嵌封面解析；
  - 正在增强：支持 Primuse 标准 M3U8 歌单导入与双端音乐库联动。

## 开发与编译构建

### 环境要求
* Node.js (推荐 v18 或 v20+)
* npm (或 yarn / pnpm)
* Windows 10 / 11 64位系统

### 快速启动
```bash
# 1. 安装项目依赖
npm install

# 2. 启动本地开发服务与 Electron 桌面客户端
npm start
```

### 打包 Windows 安装程序
```bash
# 生成 NSIS Windows 64位安装包（产物位于 dist/ 目录）
npm run build:win
```

## 架构与数据隐私

1. **纯本地数据存储**：
   - 所有的登录凭据、搜索记录、歌单缓存、用户自定义视觉预设均保存在本地环境或应用数据目录中；
   - 客户端已切断外部自动更新检测与遥测上报，零外部追踪，杜绝隐私泄露。
2. **多源音轨与渲染管线**：
   - 主管线基于 Electron + Node.js 本地微服务 (`server.js`) 处理音频流与解密逻辑；
   - 渲染层基于 GSAP + Canvas / WebGL 驱动高性能粒子与节奏变换。
